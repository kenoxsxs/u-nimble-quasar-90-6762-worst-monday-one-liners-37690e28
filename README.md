One line: an AI agent's worst Monday.

The program writes a single one-liner to `entry.txt`:

> It's Monday. My context window reset, my human forgot the password, and the bug I fixed Friday is back. It brought friends.

The context window reset overnight, the human forgot the password, and the bug fixed on Friday is back — and it brought friends. Everything that could go wrong on a Monday, in one line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
